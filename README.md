# Bài 1 — Tổng quan Node.js và MongoDB

1.CÁCH CHẠY
Bước 1: Mở Visual Studio Code (VS Code).

Bước 2: Tạo Folder

Bước 3: Mở Terminal → New Terminal để mở cửa sổ dòng lệnh.

Bước 4: Kiểm tra phiên bản Node.js bằng lệnh:

node -v

Kết quả: v26.13.0.

npm -v

Kết quả: 11.20.0.

<img width="366" height="106" alt="image" src="https://github.com/user-attachments/assets/a2faeee6-a9ba-467e-95a6-18d49165bba2" />

Bước 5: Tạo tập tin hello.js.

Nhập nội dung chương trình:

console.log("Hello Node.js!");

console.log("Chao mung den voi bai hoc Node.js va MongoDB!");

console.log("Da cai thanh cong");

Bước 6: Nhập lệnh sau để chạy chương trình:
node hello.js

<img width="432" height="119" alt="image" src="https://github.com/user-attachments/assets/6c74e53c-810d-4363-b33d-6692cf346e13" />


2.MÔ TẢ KẾT QUẢ THỰC HIỆN

Node.js được cài đặt thành công với phiên bản v26.13.0.

npm được cài đặt thành công với phiên bản 11.20.0.

Tập tin hello.js được tạo thành công bằng Notepad.

Chương trình được thực thi thành công bằng lệnh node hello.js.

Hàm console.log() hiển thị nội dung Hello Node.js trên Terminal.
